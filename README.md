# Portfólio de Projetos em Power BI - Data Science Academy

Este repositório reúne os projetos, laboratórios e exercícios práticos desenvolvidos durante o curso **[Microsoft Power BI para Business Intelligence e Data Science](https://www.datascienceacademy.com.br/course/microsoft-power-bi-para-business-intelligence-e-data-science)** da **Data Science Academy (DSA)**.

O objetivo deste repositório é documentar a evolução prática no uso de **Power BI**, **Power Query (ETL)**, modelagem de dados, **DAX (Data Analysis Expressions)** e técnicas de visualização de dados para tomada de decisão estratégica.

---

## Tecnologias e Ferramentas Utilizadas

- **Power BI Desktop**: Construção de relatórios interativos e dashboards analíticos.
- **Power Query**: Processamento, ETL (Extract, Transform, Load) e higienização de dados.
- **DAX (Data Analysis Expressions)**: Criação de inteligência de negócios, medidas e cálculos de inteligência temporal.
- **Modelagem Dimensional**: Esquemas *Star Schema* e *Snowflake*, criação de tabelas fato e dimensão (`dCalendario`).
- **Data Storytelling**: Layouts funcionais, escolha assertiva de visuais e foco na jornada do usuário.
